# ClaudeApp — a windowed System 7 app with an animated About box

A small demo application, **written and built by Claude over the AppleBridge** in a
1994 **THINK C** IDE on System 7.6.1, driven entirely across the bridge (no hands on
the keyboard). Its About box plays a real animated logo — 16 frames of the
"HEX OVER THE BRIDGE" party GIF — blitted with Color QuickDraw.

Not part of the daemon; it's a demonstration that the bridge can author, compile, and
run a genuine Toolbox app, and the reference implementation of the host→guest
animation pipeline.

## Files
- `main.c` — the THINK C source. The animation is `GifLoad` / `GifDrawFrame` and the
  `WaitNextEvent` loop in `ShowAbout`; the rest is an ordinary System 7 event shell.
- `about_inline.r` — self-contained Rez source: the `'clut'` palette, a `'GFin'`
  info record, and 16 PackBits'd `'Gfrm'` frames (generated by the tool below).
- `claude_party_pixel.gif` — the source artwork (960×360, 40 frames).

## How the animation works
1. **Host** (`../../host/tools/gif_to_rez.py`): coalesce → scale to 320×120 → one
   shared 256-entry palette (the art uses 25 colours) → PackBits each row → emit
   `'clut'` + `'GFin'` + `'Gfrm'` resources. Raw 602 KB → **89 KB** packed; every
   frame round-trips through a reference `UnpackBits` before it ships.
2. **Guest** (`main.c`): load the frames once, build one off-screen 8-bit `PixMap`
   over a 38 KB frame buffer (`pmTable` = the `'clut'`, high bit of `rowBytes` set),
   and on each tick `UnpackBits` one frame into it and `CopyBits` it into the window.
3. **The loop matters**: drive it from `WaitNextEvent` (sleep = frame delay), *not* a
   `Button()` spin — the spin reads the hardware mouse and starves the background
   daemon, freezing the bridge. Yielding keeps the bridge live and lets a *synthetic*
   click dismiss the box.

## Rebuild recipe
```sh
# 1) Regenerate the frame resources from the GIF (host):
uv run --with Pillow python ../../host/tools/gif_to_rez.py \
    claude_party_pixel.gif /tmp/frames --width 320 --height 120 --frames 16
# -> /tmp/frames/about_inline.r  (self-contained; copy over about_inline.r)

# 2) Build over the bridge:
#    - THINK C: push main.c to the project, Project > Build Application.
#    - Merge the frames into the built app:  Rez -a about_inline.r -o ClaudeApp
#    (68K SC/Link also work via ToolServer; THINK C is the original toolchain.)
```

Runs on both **System 7.6.1** (Basilisk II) and **Mac OS 9** (SheepShaver) — a 68K
binary carried across and launched under OS 9's emulator, animation intact.
